# Factory Tycoon Guide

Factory Tycoon is a deterministic resource management simulation embedded within the AI Book World Builder. It serves as both a "Zen Mode" distraction for writers and a demonstration of complex React state management patterns.

## User Guide

### How to Play

**Goal**: Build a profitable factory chain by converting raw resources into valuable products.

**Resource Chain**:
1.  **Ore** (Raw Material) -> Produced by **Mines**.
2.  **Ingot** (Refined Material) -> Smelted from Ore in **Smelters**.
3.  **Gadget** (Finished Product) -> Assembled from Ingots in **Factories**.
4.  **Cash** (Currency) -> Earned by selling Gadgets in **Markets**.
5.  **Science** (Research) -> Generated by **Labs** to unlock upgrades.

### Controls
-   **Select Building**: Click a building icon in the bottom palette.
-   **Place Building**: Left-click on any empty grid tile.
-   **Remove Building**: Right-click on an existing building (Note: No refunds!).
-   **Pause/Resume**: Use the controls in the HUD panel.

### Understanding Status
Buildings have color-coded status indicators:
-   🟢 **Green (Running)**: Operating normally.
-   🟡 **Yellow (Starved)**: Waiting for input resources (e.g., a Smelter waiting for Ore).
-   🔴 **Red (Blocked)**: Output is full or storage is at capacity.

## Developer Guide

### Architecture

The Factory Tycoon engine is built on a **Deterministic Simulation Loop** pattern, ensuring that the game state is reproducible and testable.

#### Core Components
-   **Engine (`engine.ts`)**: The pure logic function `simulateTick(state)` that calculates the next game state. It has no side effects.
-   **State Store (`store.tsx`)**: Uses `React.useReducer` to manage the `GameState`. It handles the game loop interval and dispatches `TICK` actions.
-   **Rendering (`GameCanvas.tsx`)**: A pure presentation component that renders the grid using CSS Grid and SVG/Lucide icons.

#### Data Model
The `GameState` is a strictly typed object defined in `types.ts`:
```typescript
interface GameState {
  cash: number;
  tickCount: number;
  inventory: Record<ResourceType, number>;
  buildings: BuildingEntity[];
  // ...
}
```

### Key Implementation Details

1.  **Tick-Based System**: The game advances in discrete "Cycles" (ticks). All calculations (production, movement, consumption) happen in the `simulateTick` function.
2.  **Optimized Rendering**: The `GameTile` component uses `React.memo` with a custom comparator to prevent re-rendering of static tiles.
3.  **Theme System**: The game uses a scoped CSS theme (`factory-theme.css`) to ensure its styles (colors, fonts) do not bleed into the main application.
